# GitHub Repository Setup Notes

Use the following public-facing metadata when creating the repository.

## Suggested repository name

`stock-sync-monitor`

## Description (About)

`Windows desktop tool for monitoring and synchronizing inventory between Microsoft SQL Server and a compatible e-commerce API.`

## Suggested topics

`python` `windows` `inventory-management` `stock-synchronization` `sql-server` `pyodbc` `customtkinter` `ecommerce` `api-integration`

## Suggested About website

Leave blank unless you have a public project page or documentation site.

## Visibility

Choose **Public** only after reviewing the complete repository and confirming that no secrets, private business information, or customer data are included. Otherwise choose **Private**.

## Files to upload

Upload the contents of this folder to the root of the new repository. The `README.md` must be at the repository root so GitHub displays it on the project home page.

## Before publishing

1. Search all files for passwords, tokens, cookies, private IP addresses, internal hostnames, database names, and private domains.
2. Confirm that `api_config.json`, `.env`, logs, Excel exports, and database files are not included.
3. If any credential was previously committed, rotate it; a later deletion does not erase it from Git history.
4. Add screenshots only after redacting private information.
5. Select and add an explicit open-source license only if you are willing to grant those permissions.
