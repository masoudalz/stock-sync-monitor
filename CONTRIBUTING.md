# Contributing

Thank you for your interest in improving Stock Sync Monitor.

## Before Opening an Issue

- Check whether the issue has already been reported.
- Include your Windows version, Python version, and relevant package versions.
- Describe the expected behavior and the actual behavior.
- Include sanitized error messages or logs when useful.
- Remove database names, server addresses, API URLs, authorization headers, cookies, CSRF tokens, and customer/product-sensitive information.

## Pull Requests

- Keep changes focused and explain why they are needed.
- Do not add real credentials, production data, or private configuration files.
- Test changes with a non-production database/store account where possible.
- Update the README when installation, configuration, or behavior changes.

## Security

Never attach `api_config.json`, database backups, browser cookie exports, or unredacted logs to issues or pull requests.
